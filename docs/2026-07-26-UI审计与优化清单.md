## 二、梯度 B —— 结构整顿（建议 2-3 天，解决"布局不合理 + 管理麻烦"）

### 主站信息架构（来自 ia / flows 维度）
- **B-1【高】交易执行台从弹窗升为一级页面**：实盘/模拟切换、手机桥接、下单总闸、双端资金/委托全在 `todayOrdersModal`(index.html:856-1036，90vw/1400px)，入口仅顶栏一个小字，点空白即关、每次打开清空当日委托。它比 6 个页签都重要，却没页签/没 URL/没状态保持。
- **B-2【高】抽独立「系统设置」页**：AI Key、券商接口、企微/飞书/钉钉/TG 推送埋在策略中心右栏第 5 个小 Tab（index.html:1332-1475），新用户根本找不到。
- **B-3【高】建统一「风控中心」**：持仓/仓位/日限/熔断至少散在 4 处各配各的、互不联动（监控 acctBar / AI交易 aitSettings / 因子激活 vibeActivate / 实盘确认 liveModeModal），"改一处漏三处"。
- **B-4【高】开盘就绪检查条**：决定"今天会不会真下单"的 5 个开关分散在 3 处 UI，无聚合视图。把交易执行台里的 5 灯总览搬到监控首屏顶端。
- **B-5【中】导航改分组侧边栏**：顶栏 13 元素、<1500px 折两行；真实目的地约 20 个（6 页签下还有 2-3 级子 Tab）。改「交易/研究/复盘/AI/系统」侧栏，顶栏只留 logo/运行态/实盘态/用户。
- **B-6【中】加 URL 路由**：`switchPage` 纯 class 切换，F5 永远回监控中心、浏览器后退失效、二级 Tab 全丢。改 `location.hash` + 载入恢复。
- **B-7【中】程序化跳页硬编码页签序号**（`.ntab[1]`/`[0]`），增删页签会静默跳错 → 给 ntab 加 `data-page` 按名查找。
- **B-8【中】"交易/模拟"概念在 4 处重叠**：模拟盘至少 4 个互不相通账户（本地模拟/AI模拟/手机模拟/券商模拟），用户分不清单子进了哪个账户。
- **B-9【中】"产业链研报"页签名不副实**：通用智能搜索藏在其第 3 个子 Tab；复盘龙虎榜要三级点击。

### 管理后台（来自 admin 维度）
- **B-10【高】工作台/使用统计的图表、最近活动、通知铃铛几乎全是硬编码假数据**（`Math.random`），与真数据同屏混排，实盘平台会误导决策 → 接真实聚合接口或先标注"示例数据"下线。
- **B-11【高】"修改密码"下拉打开空白页**（page-change-pwd 是空 div）→ 改指向个人中心改密卡片。
- **B-12【高】后台无任何返回主站入口**，主站↔后台单向割裂 → 侧栏加"⬅ 返回主站"。
- **B-13【高】后台无 URL 路由**：F5 回工作台、后退直接退出后台、页签不持久。
- **B-14【中】积分修改"一个输入框两种语义"**（充值量 vs 目标值），误点会把用户总积分覆盖，且成功静默无提示 → 拆按钮 + 变更预览 + toast。
- **B-15【中】反馈处理低效**：逐条手动保存、保存后滚回顶部、无分页、默认不聚焦待处理。
- **B-16【中】菜单频率倒挂**：9 项"系统管理"永远展开，高频"问题反馈"默认折叠。
- **B-17【中】用户建后无法编辑资料**（编辑分支存在但无入口且不回填）。
- **B-18【中】三套对话框混用**：自研 showConfirm / 原生 confirm / 原生 alert / 连环 prompt（更新日志编辑）。
- **B-19【中】后台依赖谷歌字体+cdnjs+jsdelivr 三个境外 CDN**，国内首屏白屏/图标变方块（主站已本地化，后台被落下）。
- **B-20【低】残留 5 色主题切换器**与糖果主题打架、页签右键 `tabCtxMenu` 未定义、12 处手动刷新+静默失败、备案脚注 fixed 遮内容底部、移动端侧栏无抽屉/表格无横向滚动。

## 三、梯度 C —— 设计系统重做（建议 1 周，根治"丑"和"越改越乱"）

### 视觉系统（来自 visual / pages 维度）
- **C-1【高】塌缩三代主题为一套 design token**：颜色/字号/间距/圆角/阴影。现状：16 种字号、8 种字重（含非标准 850/950）、18 种圆角、阴影 30 处一次性值，`:root` 只有颜色 token。
- **C-2【高】修加载顺序断裂**：`app-widgets/app-pages/app-feedback` 三个 CSS 在 `theme-candy` 之后加载，糖果修复被静默推翻（深绿 toast、高饱和旧红绿、浅字浅底徽章）→ 三个 link 移进 head 或合并塌缩。
- **C-3【高】统一语义色 token**：`--up/--down/--buy/--sell/--info`。现状"买入"一处红一处绿、涨跌红绿三套值、`--blue` 值竟是粉色（命名倒挂）——真钱平台的方向色不能翻转。
- **C-4【高】对比度整改**：主粉 #FF7B93 仅 2.47:1、涨色 3.73:1、次级文字 2.25~3.16:1 均不达 AA；盈亏小字最需可读却不达标。
- **C-5【高】K线弹窗深浅撕裂**：白外壳里嵌深黑周期条/五档盘口/画布（59 处 JS 硬编码深色）→ 色值收敛到 CSS 变量，画布底色 `getComputedStyle` 读取。
- **C-6【中】未加载的 Noto Sans SC + 850/950 靠合成**（笔画发糊）、`--hover` token 从未定义致 8 处 hover 静默失效、`rb-effects.css` 深色动效残留（冷色 aurora/蓝下划线/黑卡阴影）、`cd-linear.css` 13.9KB 死文件。

### 组件与工程（来自 pages 维度）
- **C-7【高】统一弹窗/表格/空态组件**：现有 5 套弹窗 + 71 处原生 alert/confirm、9 套 Tab CSS + 10 个切换函数、5 种表格实现；`.empty-hint` 类被 29 处引用但从未定义（空态全裸奔）。
- **C-8【中】`data-ui-click` 全量迁到 `data-action` 具名分发**（app-core.js 已有 `handleUiAction` 这套好的）→ 迁完即可移除 CSP 的 `unsafe-eval`（A-1 的临时放行收紧）。
- **C-9【中】内联样式治理**：index.html 约 400 处 style=、JS 拼 HTML 约 730 处，换主题永远漏掉 → 内联样式只留布局，颜色迁入 class。
- **C-10【中】次级页响应式**：复盘/产业链固定多栏无断点，窄屏被 overflow:hidden 裁掉；`<760px` 零断点。
- **C-11【中】前后台抽公共 `tokens.css`**：现为两套零共享技术栈（连图表库都不同 Chart.js vs ECharts），改一个品牌色要改两处。
